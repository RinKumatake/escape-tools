# 🔑 Escape Room Passcode Generator

脱出ゲームのギミックや仕掛け作りに特化した、ブラウザで動くシンプルなパスコード生成ツールです。

👉 **[Webツールを開く](https://<ユーザー名>.github.io/<リポジトリ名>/)**

---

## 🎯 主な機能

- **4種類の生成モード**
  - **バイナリ（0と1のみ）**: レバーの上下、スイッチの切り替え、ランプの点灯/消灯などの仕掛けに最適（※2桁以上は「全部0」「全部1」を自動除外）
  - **指定範囲の数字**: 最小値と最大値を自由に指定可能（例: サイコロ用の `1〜6`、トランプ用の `1〜9` など）
  - **ひらがな（あ〜ん）**: 和風の文字盤や五十音ギミックに最適（清音46文字）
  - **アルファベット（A〜Z）**: 英語のダイヤル錠や暗号パズルに最適（大文字26文字）
- **重複なしオプション**
  - 指定した候補の中で「すべて異なる文字・数字」の組み合わせを生成可能
- **柔軟な文字数・桁数指定**
  - 1桁（1文字）から最大20桁まで自由に指定可能
- **半角スペース区切り表示**
  - 生成結果の文字間に半角スペースを入れて視認性をアップ（例: `1 2 3 4` / `A B C D`）
- **ワンクリックコピー & リセット**
  - 表示されている形式のままクリップボードへ即座にコピー
  - リセットボタンで初期設定にワンクリック復元
