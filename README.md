# 🔑 Escape Room Passcode Generator

脱出ゲームのギミックや仕掛け作りに特化した、ブラウザで動くシンプルなパスコード生成ツールです。

👉 **[Webツールを開く](https://rinkumatake.github.io/escape-tools/)**

---

## 🎯 主な機能

- **バイナリ生成（0と1のみ）**
  - レバーの上下、スイッチの切り替え、ランプの点灯/消灯などの仕掛けに最適
  - 「全部0」「全部1」の単調な組み合わせを自動で防止
- **範囲指定の数字生成**
  - ダイヤル錠、テンキー、金庫などの入力パスワード作成に最適
  - 最小値と最大値を自由に指定可能（例: サイコロ用の `1〜6`、トランプ用の `1〜9` など）
- **重複なしオプション**
  - 指定した範囲内で「すべて異なる数字」の組み合わせをワンクリックで生成
  - 桁数が範囲を超えた場合の自動バリデーション付き
- **桁数指定**
  - 2桁〜10桁まで柔軟に指定可能
- **ワンクリックコピー & リセット**
  - 生成したコードをクリップボードに即座にコピー
  - リセットボタンで初期設定（バイナリ・4桁）にすぐ復元可能
